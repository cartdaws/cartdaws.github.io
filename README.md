# INTRUDER V2 (experiment)

An experimental rework of INTRUDER as a first-person alien evolution game about grief. **This does not replace V1.**

- **Run it:** `npm install` once, then `npm run dev`, then open http://localhost:5174
- **Plan and assessment:** [docs/V2_ASSESSMENT.md](docs/V2_ASSESSMENT.md). Awaiting approval: V2 story and gameplay work has not started
- **V1 lives at** `Desktop/Intruder-Rebuild` and https://cartdaws.github.io/intruder/. Nothing here can deploy over it: there is no publish workflow and no push remote
- **V1 backup:** git tag `v1-final`, and `Desktop/Intruder-Backups/intruder-v1-ab3251c.bundle`

`STORY.md` still describes V1 and is not V2 canon.

The `v1` git remote is fetch-only, so a fix can be pulled across from V1 but nothing can be pushed to it.
